# MODNet photographic portrait matting weights

- Model: `modnet_photographic_portrait_matting.onnx`, unchanged ONNX file, 25,888,640 bytes; SHA-256 `07c308cf0fc7e6e8b2065a12ed7fc07e1de8febb7dc7839d7b7f15dd66584df9`.
- MODNet authors: Zhanghan Ke, Jiayu Sun, Kaican Li, Qiong Yan and Rynson W. H. Lau, *MODNet: Real-Time Trimap-Free Portrait Matting via Objective Decomposition* (AAAI 2022). Original project and ONNX export information: <https://github.com/ZHKKKe/MODNet> and <https://github.com/ZHKKKe/MODNet/tree/master/onnx>.
- The [HivisionIDPhotos pretrained-model release](https://github.com/Zeyi-Lin/HivisionIDPhotos/releases/tag/pretrained-model) describes the same filename as official MODNet photographic weights. The release download redirects to a host unavailable in this sandbox. The identical-size file was retrieved as Git blob `929e054b0d6f001898d309f92b7a70b9530ec301` from [this GitHub mirror](https://github.com/ElyasOmarcodes/Ai-Model/tree/65f4ec688c98206c2561316c911171a53aaa93ef); its SHA-256 matches the independently published [MODNet model checksum](https://huggingface.co/DavG25/modnet-pretrained-models). No conversion or alteration was made by Wallpep.
