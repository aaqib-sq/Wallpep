# Wallpep font library — inventory

Own library for the Wallpep personal wallpaper app (Android, package dev.wallpep). Every file below comes from the Google Fonts repository (github.com/google/fonts, main branch) — the `ofl/` directory, plus five families that live in that repo's `apache/` directory (Apache-2.0). No font was taken from DepthX, from any APK, or from any other app's assets. Each file was verified with the `file` command to be a valid non-empty TrueType font.

Total valid files: 185
