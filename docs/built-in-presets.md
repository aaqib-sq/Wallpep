# Built-in presets

Home offers four offline designs. Tap a card to open its live editor, then tap Apply to open Android's wallpaper chooser; the system still requires confirmation and a destination. You can instead tap “Apni photo se banao” to pick your own image. A preset becomes a collection item only when saved by editing or applying it; My Collection contains saved user designs, not the built-in catalogue.

Each preset starts from a fresh, complete `WallpaperSettings` default, with the overrides below. All use the default clock font and format, white centered clock and date, 100% opacity, the default date font and format, no particles, no parallax, neutral image adjustments, and the clock/date above any foreground cutout. Clock/date shadows are black with X offset 0 and Y offset 4. Everything remains editable.

| Preset | Clock size / Y | Date Y | Shadow blur / opacity |
| --- | --- | --- | --- |
| Mountain Dusk | 76 / 29 | 17 | 18 / 80% |
| Ocean Sunset | 72 / 30 | 17 | 24 / 100% |
| Forest Mist | 72 / 28 | 16 | 18 / 100% |
| Blue Waves | 80 / 27 | 15 | 18 / 80% |

Images are the four original supplied JPGs, bundled unchanged. Selecting one makes a private copy using the same storage and scene renderer as user photos. The editor, saved thumbnails and live wallpaper share `WallpaperScene`. No device verification was performed for this change.
